# Sample pads

These are interface sounds from Kenney's **Interface Sounds** pack:

- Source: <https://kenney.nl/assets/interface-sounds>
- License: Creative Commons CC0 (see `KENNEY-LICENSE.txt`)
- Conversion: OGG -> MP3, 48 kHz stereo, 128 kbps

CC0 does not require attribution. The Spore ships the license text anyway so
the provenance is reviewable.

To install them into a personal VFS and mapping, run
`tools/install-samples.sh` from the repository root.
